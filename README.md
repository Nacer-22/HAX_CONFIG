# HAX_CONFIG

مستودع مستقل لملفات إعداد HAX_NON_ROOT.

- `Nacer.json`: قالب إعداد Xray/V2Ray مع حقول خادم تجريبية يجب استبدالها.
- `subscription.json`: بيان الاشتراك العام.
- لا توجد بيانات اعتماد أو عناوين خوادم حقيقية داخل القالب.

**تنبيه:** هذا المستودع Public؛ لا ترفع كلمات مرور أو UUID أو روابط خاصة قبل التأكد من أنها مخصصة للنشر العام.

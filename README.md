# HAX_CONFIG

مستودع مستقل لملفات إعداد HAX_NON_ROOT — Nacer_22.

## الملفات
- `Nacer.json`: قالب إعداد Xray/V2Ray يحتوي على مداخل SOCKS وHTTP ومخارج proxy/direct/block.
- `subscription.json`: بيان وصفي يحدد اسم المشروع وملف الإعداد المرتبط به.
- `index.html`: صفحة عربية لتنزيل الملفات.

## الحالة الحالية
الملف `Nacer.json` صالح من ناحية صياغة JSON، لكنه **قالب وليس اتصالاً جاهزاً**. يجب استبدال القيم التالية ببيانات خادمك:
- `YOUR_SERVER_HOST`
- `YOUR_USERNAME`
- `YOUR_PASSWORD`
- `YOUR_DOMAIN_TO_PROXY`

لم تتم إضافة خادم أو حساب أو رابط اشتراك حقيقي. لا تنسخ بيانات اعتماد طرف آخر.

## تنبيه الخصوصية
هذا المستودع Public. أي ملف ترفعه هنا يمكن لأي شخص قراءته. لا تضع فيه بيانات اعتماد خاصة أو روابط اشتراك شخصية ما لم تكن تقصد نشرها للعامة. عند توفير صيغة الاشتراك المطلوبة من التطبيق، يمكن إعداد ملف متوافق معها؛ البيان الحالي ملف metadata وليس ادعاءً بأنه صيغة اشتراك Happ مؤكدة.
